# DSA Coach 2.0

A personalized DSA preparation platform built with the MERN stack.

## Features

- JWT Authentication
- User Profiles
- LeetCode Integration
- LeetCode Stats Sync
- Personalized Problem Recommendations
- MongoDB Atlas Storage

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- Axios

## Setup

### Backend

cd backend
npm install
npm run dev

### Frontend

cd frontend
npm install
npm run dev
